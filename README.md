# 화면 번역기 (ScreenTranslator)

화면의 외국어 글자를 OCR로 읽어 **한국어로 번역한 뒤, 원문 위에 그대로 덮어서** 보여주는 Windows 프로그램이에요.

## 사용법
프로그램을 켜면 **버튼 창**이 떠요. 단축키를 몰라도 버튼만 누르면 돼요.

| 버튼 | 단축키 | 동작 |
|---|---|---|
| 영역 선택해서 번역 | Ctrl+Alt+T | 드래그한 영역을 한 번 번역 (번역 화면은 클릭이 통과돼요. 화면이 바뀌면 자동으로 지워져요) |
| 영역 실시간 번역 | Ctrl+Alt+L | 영역을 정하고 실시간 번역 시작/중지 (화면이 바뀔 때만 다시 번역) |
| 화면 전체 번역 | Ctrl+Alt+F | 마우스가 있는 모니터 전체 번역 |
| 번역 지우기 / 중지 | Ctrl+Alt+X | 번역 지우기, 실시간 중지 |
| 설정 | - | 갱신 주기, 번역 엔진(DeepL), 자동 실행, 업데이트 |

- 창을 닫아도 트레이에서 계속 실행돼요. 트레이 아이콘을 누르면 창이 다시 열려요.
- Windows 시작 시 자동 실행으로 켜면 창 없이 트레이로만 시작해요.

## 설치 (처음 한 번)
1. `ScreenTranslator.cs`, `build.bat`, `version.txt` 를 한 폴더에 둬요.
2. `build.bat` 더블클릭 → `ScreenTranslator.exe` 생성 (Windows 내장 컴파일러라 설치할 게 없어요).
3. exe 실행.

## 번역 엔진과 '요청 제한' 오류
- 무료 번역 3종(Microsoft Edge 번역 → Google → Lingva, 모두 비공식)을 순서대로 자동으로 써요. 하나가 막히면 다음 엔진으로 넘어가고, 막힌 엔진은 잠시 쉬었다가 다시 써요.
- 한 화면은 요청 1번으로 묶어 보내고, 요청은 한 번에 하나씩만 보내요.
- 그래도 막히면 **설정 > DeepL 키**에 DeepL 무료 API 키를 넣어 주세요 (월 50만 자 무료, 키는 이 PC에만 저장). DeepL이 가장 먼저 쓰여요.
- 설정의 **번역 테스트**를 누르면 엔진별로 성공/실패와 이유(HTTP 코드)를 보여줘요. 실패 기록은 `%APPDATA%\ScreenTranslator\translate.log` 에도 남아요.

## 자동 업데이트 (추가 다운로드 불필요)
- 실행 30초 뒤, 그리고 6시간마다 이 저장소의 `version.txt` 를 확인해요.
- 숫자가 더 크면 `ScreenTranslator.cs` 를 받아 **이 PC에서 컴파일 → exe 교체 → 자동 재시작**해요.
- 새 버전 올리는 법: `.cs` 의 `AppVersion` 숫자와 `version.txt` 숫자를 **같은 값으로** 올려서 `main` 브랜치에 push.
- 빌드가 실패하면 기존 버전을 그대로 쓰고 그 버전은 건너뛰어요 (`%APPDATA%\ScreenTranslator\update.log` 에 기록).
- 설정 > "지금 업데이트 확인"으로 바로 확인할 수 있어요.

## 요구사항
- Windows 10/11 (내장 OCR 사용). 번역할 언어의 OCR 언어팩 필요: 설정 > 시간 및 언어 > 언어 및 지역 > 언어 추가
- 인터넷 연결

## 번역 메모리 (토큰 절약)
- 번역한 문장은 `%APPDATA%\ScreenTranslator\memory.tsv` 에 저장돼 다음 실행에도 다시 쓰여요. 같은 문장은 번역 요청을 보내지 않아요.
- OCR이 한두 글자 흔들린 같은 문장(대소문자, I/l/1, O/0)도 재사용해요. 숫자가 다르면 재사용하지 않아요.
- 설정 > 번역 메모리에서 절약한 글자 수 확인, 폴더 열기, 지우기. 파일은 직접 고쳐도 돼요 (원문⇥번역).

## OCR 언어 설치
- 읽을 수 없는 언어는 OCR 언어팩이 필요해요. 패널의 **OCR 언어 설치** 버튼(또는 트레이 메뉴, 설정)에서 언어를 체크하면 설치해요.
- 설치 전에 확인 창이 뜨고, Windows의 관리자 권한 확인 창에서 '예'를 눌러야 진행돼요. 번역할 글자를 못 찾았을 때도 설치를 제안해요.

## 디버그 모드
- 버튼 창의 **디버그 모드** 체크(또는 Ctrl+Alt+D)를 켜면 번역 화면 위에 OCR 상자(회색=원본, 하늘색=통과, 빨강=걸러냄, 주황=최종 번역 칸)와 진단 요약(OCR 시간·번역 시간·엔진·언어별 점수·줄 수 변화·오류)이 겹쳐 보여요.
- 매번 `%APPDATA%\ScreenTranslator\debug_last.txt`(전체 기록)와 `debug_last.png`(OCR이 본 캡처)를 저장해요. **디버그 폴더** 버튼으로 열 수 있어요.

- v14: 번역 기억(확정 번역) 추가 - 맞는 번역은 '👍 번역 기억' 버튼으로 저장(틀린 번역은 고쳐서 저장), 같은 문장·같은 자리의 비슷한 문장은 번역기 없이 그대로 사용, 단어(용어) 사전은 실시간 번역에도 적용, '기억 관리' 창에서 보기·수정·삭제·용어 추가

- v10: 큰 화면을 2배 확대해서 읽다가 글자가 조각나던 문제 수정(큰 화면은 원래 크기로 읽음), 조각난 글자 이어붙이기, 세로로 긴 쓰레기 줄 제거
